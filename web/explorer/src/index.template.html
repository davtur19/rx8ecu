ROM contexts & firmware models

The project uses two address contexts for symbols + callgraph: 60E1D400 (RE baseline) and 60E0FC00 (Z-line, equinox reference). The calibration tables can be viewed in any of the 9 stock firmware models using the Firmware model selector in the header: addresses come from data/table_addr_map_long.csv (per-model map, never a global shift) and values are extracted from the matching roms/stock/*.bin. Functions and symbols are not shifted when the selected model is outside their native contexts.
