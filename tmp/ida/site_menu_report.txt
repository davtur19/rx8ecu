## Summary

Integrated ROM Explorer and ECU Pin Emulator into a single GitHub Pages site
with a landing menu at https://davtur19.github.io/rx8ecu/

## New Site Structure (dist/)

```
dist/
  index.html          ← Landing page with 2 cards (menu)
  explorer/
    index.html        ← ROM Explorer (existing, unchanged logic)
    app.js, style.css, data.json, data.js
    models/*.json     ← Per-model value files (8 files)
    .nojekyll
  emu/
    index.html        ← ECU Pin Emulator (existing, unchanged logic)
    app.js, style.css, pins.json
```

## Routing

- `/`           → Landing page (two big cards)
- `/explorer/`  → ROM Explorer (full app, unchanged)
- `/emu/`       → ECU Pin Emulator (full app, unchanged)

## Deployment

When pushed, the pages.yml workflow will:
1. Build ecu-emu: `make -C web/ecu-emu build`
2. Build explorer + landing page + copy emu: `python3 web/explorer/build_site.py`
3. Upload `web/explorer/dist/` as Pages artifact
4. Deploy to GitHub Pages

The site URL https://davtur19.github.io/rx8ecu/ will show the landing page.
