ISSUES FOUND & FIXED
--------------------
1. [FIXED] JS error: "rpm is not defined" in renderRegisters (app.js:554)
   - Root cause: rpm was a local const inside computePinStates(), but renderRegisters()
     referenced it as a free variable. Fixed by reading sensorState.rpm locally.
   - File: web/ecu-emu/src/app.js line 554

2. [FIXED] Missing responsive CSS for emu (no @media queries)
   - Root cause: .main used fixed grid-template-columns:280px 1fr 320px with no
     mobile fallback. On <768px, panels overlapped, legend clipped, header broke.
   - Fix: Added @media (max-width:768px) block to web/ecu-emu/src/style.css:
     - body overflow:auto, height:auto (allow scrolling)
     - header flex-wrap, legend border-top:none, centered
     - .main switches to display:flex;flex-direction:column
     - Panels remove border-right, set overflow-y:visible
     - Connector: max-height:50vh, overflow-y:auto
     - Schematic: min-height:300px
     - Scenarios: flex-direction:row;flex-wrap:wrap
   - File: web/ecu-emu/src/style.css
