Architecture
------------
  Cooperative 4-priority scheduler:
    S0 (priority 0): Engine control — highest, cannot be interrupted
    S1 (priority 1): I/O processing
    S2 (priority 2): Safety monitoring
    S3 (priority 3): Idle / background — lowest

  Fixed-size circular task queue:
    100 entries × 8 bytes at 0xFFFFD4E0
    Write index: 0xFFFFDFB4 (uint16)
    Read index:  0xFFFFDFB6 (uint16)

  Dispatch table at 0x6873C: 8-byte records
    word = handler_addr | (type << 24) | (priority << 28)
    Type encoding (bits 24-26):
      0: Basic handler (r4=task_id)
      1: Sub-function (r4=task_id, r5=sub_func)
      2: Buffer pointer (r4=task_id, r5=buffer_ptr)
      3: Reserved
      4: Timer callback (r4=timer_id)

Context Switch (SH-2)
---------------------
  Save (0x3AD8):
    Stack frame: [SR][PR][r8-r14][r5][GBR][MACH][MACL]
    Optional (type 4): [fr12-fr15]
    Frame size: 52 bytes (basic), 68 bytes (with FP)

  Restore (0x3238):
    Reverse of save, using mov.l @(offset, sp), reg sequence
    Optional (type 4): fr12-fr15

  Note: C framework provided; full implementation requires
  SH-2 inline assembly for register save/restore.

Queue Operations
----------------
  Entry layout (8 bytes):
    [+0]: uint32 dispatch record
    [+4]: uint32 argument

  Enqueue: writes to [write_index], advances with modulo
  Dequeue: reads from [read_index], advances with modulo

  Priority-based dispatch:
    If task_priority <= current_priority: dispatch immediately
    If task_priority > current_priority: re-enqueue for later

Scheduler Flow
--------------
  1. Check if queue has entries
  2. Dequeue next entry
  3. Extract priority from dispatch record
  4. If priority <= current_priority:
     a. Save old priority
     b. Set current_priority = task priority
     c. Context switch (save current task)
     d. Dispatch to handler
     e. Context switch (restore)
     f. Restore old priority
  5. If priority > current_priority: re-enqueue
  6. Repeat until queue empty
