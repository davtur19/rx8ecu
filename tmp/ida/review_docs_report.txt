SECTION 3: ERRORS FOUND
================================================================================

### ERROR 1: can_tx_send_frame address mismatch
- Files: ECU.md:81, CAN_PROTOCOL.md:144, FINDINGS.md:588/594/608
- Issue: All docs claim can_tx_send_frame at 0x9AE4. IDA shows the function
  at 0x29A0C. The CSV lists 0x29A0C as "can420TXPack". IDA lookup of 0x9AE4
  resolves to 0x29A0C (function start). No code at 0x9AE4 is named
  can_tx_send_frame in IDA or CSV.
- Severity: HIGH — readers will look at wrong address
- Recommended fix: Verify the correct address. The function may have been
  redefined to span both 0x9AE4 and 0x29A0C, or 0x9AE4 may be a wrapper.
  Check if 0x9AE4 is the actual function entry (prologue) or if 0x29A0C is.

### ERROR 2: DTC primary table base address inconsistency
- Files: IDA_ANALYSIS.md:705 vs FINDINGS.md:262
- Issue: IDA_ANALYSIS.md says "21 entry × 52 byte a 0xFFFF8928" but
  FINDINGS.md says "base 0xFFFF8930, stride 0x34, 21 rows" and verifies
  0xFFFF8930 + 21*0x34 == 0xFFFF8D74. Line 142 of IDA_ANALYSIS.md itself
  says "0x444-byte table init at 0xFFFF8930 (21 rows × 0x34)".
- Severity: MEDIUM — internal inconsistency within IDA_ANALYSIS.md
- Recommended fix: Correct line 705 to 0xFFFF8930 (matches line 142 and FINDINGS.md)

### ERROR 3: symbols_60E1D400_merged.csv row count off-by-one
- Files: IDA_ANALYSIS.md:210
- Issue: Doc says "2790 rows". Actual file has 2791 lines (1 header + 2790 data
  rows). This is technically correct (2790 data rows) but could be clarified.
- Severity: LOW
- Recommended fix: Clarify "2790 data rows" or leave as-is

### ERROR 4: RAM_VARIABLES.csv address count off-by-one
- Files: IDA_ANALYSIS.md:239
- Issue: Doc says "1613 addresses". Actual file has 1614 lines (1 header + 1613
  data rows). Same as above — technically correct.
- Severity: LOW
- Recommended fix: Clarify "1613 data rows" or leave as-is

### ERROR 5: IDA_ANALYSIS.md duplicates ECU.md content
- Issue: The RTOS section (lines 245-368) in IDA_ANALYSIS.md is nearly
  identical to the RTOS section (lines 190-218) in ECU.md. Similarly, the
  serial section, engine section, EEPROM section, and DTC section overlap
  heavily. This creates maintenance burden and divergence risk.
- Severity: LOW — duplication, not error
- Recommended fix: Consider consolidating: keep IDA_ANALYSIS.md as the deep
  technical reference and ECU.md as the high-level overview with pointers.
