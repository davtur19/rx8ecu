# Annotated assembly sources — 9 public stock ROMs

Generated by `tools/organize_src.py` (capstone SH-2 + `tools/disasm_sh2e.py`
fallback, self-correcting force loop), exactly mirroring the byte-exact
whole-ROM lift of `tools/rom_rebuild.py`. Every file below reassembles with
`sh-elf-as -big` + `sh-elf-ld -Ttext=0x0` + `sh-elf-objcopy -O binary` to a
byte-identical copy of the source ROM (`cmp` verified).

The dataset also includes a 10th ROM — `[REDACTED]` (the project owner's
personal live-ECU dump) — whose annotated source exists and is byte-exact
rebuildable, but it is **kept private** and not shipped here (evidence in
[VERIFICATION.md](../VERIFICATION.md)).

Coverage = words in the code window `0x800..0x60000` (195,584 words) that are
emitted as real instructions (not `.word`). The remainder is byte-exact data
(literal pools, calibration, jump tables, padding, strings).

Notes:

- **Function labels** = `! --- name 0xADDR-0xEND [source] ---` header comments.
- **.word lines** = total raw `.word 0x....` lines in the file (whole ROM, incl. vector
  table and top-of-ROM data).
- **Coverage** = window `0x800..0x60000` only; the raw disassembler lift is ~93.8%,
  the difference to the table being words the self-correction loop forces back to
  `.word` because GNU-as has no syntax for the SH-2E `0x82nn/0x86nn mov.l @(disp,Rm)`
  encodings (byte-exact by construction).
- **60E1D400** additionally carries one `! [class] 0xADDR..0xADDR (N words)` comment
  per `.word` run start from `analysis/data_regions_60E1D400.csv`
  (1,485 of 1,491 classified runs; 6 run starts were re-lifted to instructions by the
  fallback decoder and are correctly not commented). Classes: literal_pool, padding,
  unknown_data, jump_table, string.
- **Symbols**: 60E1D400 uses `symbols/symbols_60E1D400_merged.csv`
  (ida-ai + ghidra-hand-xmap); 60E0FC00 uses `symbols/symbols_60E0FC00.csv`
  (plus `symbols/symbols_60E0FC00_ghidra.csv`). The other seven ROMs' per-ROM
  `symbols/symbols_<ROM>_xmap.csv` merged tables were generated by
  `tools/xmap_names.py` (60E0FC00 ghidra-hand names x-mapped by code signature
  onto derived function entries; 239–300 high-confidence transfers per ROM, rest
  `FUN_xxxxxx` [derived]) and are kept in private storage (not shipped); the
  public repo ships the kept CSVs only. The private [REDACTED] source used
  `symbols/[REDACTED]` (also not shipped).
- All ROMs share `symbols/cal_tables.csv` for `! cal[...]` comments (60E1D400
  addresses; 1,209 of 1,210 entries land in-ROM).
