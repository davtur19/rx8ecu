===============================================================
  RX-8 S1 PCM — HARDWARE REFERENCE (Denso)
===============================================================

  NOTE: This file is ALIGNED to the authoritative board analysis in
  `docs/notes/HARDWARE.md` (user-inspected PCB, front+back, closed IC
  inventory). Component names and CPU identity below follow that file;
  earlier references to crystal "X402" and a single "IC400 second large
  QFP" were superseded (the board's crystal is X430 and the IC inventory
  uses IC404/IC840/IC780/IC820/IC830 etc.).

  PCB P/N:      279721-3210 (board silk; Denso unit-level P/N 279700-3313
                 per `docs/notes/KNOWLEDGE.md`)
  Supply:       12V automotive
  Connector:    Single multi-row pin header (bottom edge)

===============================================================
MAIN CPU — Renesas SH7055 (SH-2E)
===============================================================

  Architecture: SH-2E, 32-bit RISC, big-endian (Hitachi HD64F7055 / SH7055)
  ROM:          512KB internal flash (0x00000000-0x0007FFFF)
  RAM:          32KB (0xFFFF6000-0xFFFFDFFF)
  Clock:        External crystal X430 (10 MHz), per `docs/notes/HARDWARE.md`

===============================================================
IC INVENTORY (closed per `docs/notes/HARDWARE.md`)
===============================================================

  19 ICs total (18 front, 1 back). Key parts:

  IC430          Renesas/Hitachi SH7055 (marking `...7055F40`)
                 Main CPU — biggest chip, under crystal X430, above IC420.

  IC404          Denso custom ASIC (`D151815-8551` / `SC515616MFC`)
                 Large QFP, notched corners. Candidate: companion
                 timing/waveform ASIC. Distinct from `151821-1280` (IC780).

  IC840          Denso ASIC (`~151811-2870`) — driver row, same family.

  IC780          Denso ASIC `151821-1280` — ignition coil driver guess.
  IC820          Denso ASIC `151821-1280` (identical to IC780) — paired
                 with IC830, near crystal X430. Ignition coil driver guess.
  IC830          Denso ASIC `151821-1280` (identical to IC780/IC820) —
                 ignition coil driver guess.

  IC705/IC703/IC701  Sanken SPF0001 (power transistor arrays) —
                 per-injector or per-coil low-side drivers (3 identical).

  IC640/IC660/IC850  Fuji Electric F5041 (Intelligent Power MOSFET, SOP-8)
                 Solenoid/lamp/relay-fuse low-side drivers (3 identical).

  IC520          NXP/Freescale MC33186DH (automotive H-Bridge, 150 mΩ)
                 Candidate: ETB (drive-by-wire throttle) motor driver;
                 matches the `FUN_0x8F62` ETB loop in `docs/notes/ECU.md`.

  IC420          ABLIC S-93C56C — 256-byte EEPROM, 3-wire SPI
                 (immobilizer keys, paired data, VIN pairing byte,
                 LC checksum window per `docs/notes/KNOWLEDGE.md`).

  IC020 / IC400  Denso ASICs (SOP24; `SE585` / `SE555`) — analog
                 front-end/mux area. IC400 sits in a ~15-pair R/C filter
                 cluster; function not publicly documented.

  IC905          Toshiba `TD549A4` (only IC on the backside) — likely
                 Darlington/relay driver. Exact P/N unresolved.

  IC675          Toshiba (marking `0551H`/`AX00-H`) — unresolved P/N.
  IC190          ST Microelectronics `3029012` (SOP-8) — no datasheet.

  NOTE: `L190` (TDK, `1272`/`R2X`) is a filter/choke inductor, NOT an IC.

  All Denso ASIC functions are unconfirmed guesses — they would need
  continuity tracing to connector pins to verify (see `docs/notes/HARDWARE.md`
  "Open items").

===============================================================
EEPROM — IC420
===============================================================

  ABLIC S-93C56C (256 bytes, SPI 3-wire), bit-banged via SH7055 GPIO
  (confirmed in firmware). Contents: immobilizer keys, adaptive learned
  values. First byte `0x55` = valid marker (per `docs/notes/KNOWLEDGE.md`).
  Confirmed on PCB (marking `S93C56` + BD logo).

===============================================================
POWER DRIVERS
===============================================================

  The following assignments are INFERRED from PCB position and proximity to
  output stage components; not confirmed by trace-following or schematic

  IC705/IC703/IC701  Sanken SPF0001    Probable injector/coil low-side drivers
  IC640/IC660/IC850  Fuji F5041        Probable solenoid/lamp/relay drivers
  IC780/IC820/IC830  Denso 151821-1280 Probable ignition coil drivers
  IC520              MC33186DH         Probable ETB (DBW throttle) driver
  IC905              Toshiba TD549A4   Probable relay driver (backside)

===============================================================
CAN BUS
===============================================================

  HS-CAN:  OBD-II pins 6/14 — ECU diagnostics
  MS-CAN:  OBD-II pins 3/11 — accessories (not used for ECU)

===============================================================
BOOT / PROGRAMMING HEADER
===============================================================

  CN400 "PBL" — 13-pin single row (back edge). Confirmed pinout:
  WDT=3, FWE=6, MD1=8, TX=9, RX=10 (see `docs/notes/HARDWARE.md` and
  `docs/notes/BOOT_RECOVERY.md`). Verify with a multimeter before use.

  SW480 "RST-OPEN"   Reset jumper pad (silkscreen confirmed, unpopulated)
